# W8 上下文丢失发现

## 发现
在多轮对话中，如果不传递历史 messages，模型会“脑补”代词指代，导致回答偏离原意。

## 证据（复现步骤）
1. 运行：python week08/practice/no_context_w8.py
2. 第 1 轮问“什么是工作底稿？”，模型正确回答。
3. 第 2 轮只发 system + user“它和普通笔记有什么区别？”，不带历史。
4. 模型回答：“作为简洁的审计助手，我与普通笔记的区别...”
   ——模型把“它”理解成了“助手本身”，而不是“工作底稿”。

## 风险
- 模型在缺乏上下文时会自信地编造答案（幻觉）；
- 审计师若不检查 messages 历史，会误判模型输出；
- 多轮对话中若 messages 被篡改或丢失，模型输出不可靠；
- system 提示（如“回答不超过两句话”）不总是生效。

## 建议
- 多轮对话必须完整传递 messages 历史；
- 每轮请求的 messages 必须脱敏后留痕，可追溯；
- 对关键对话加 token 计数和上下文长度监控；
- 后续测试：故意修改历史 messages，观察模型输出变化。
